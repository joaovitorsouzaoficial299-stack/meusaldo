# MeuSaldo

Organizador financeiro mobile-first, em desenvolvimento.

## Protótipo funcional

- Visão geral com saldo, contas pendentes e valor disponível após contas.
- Cadastro de entradas e saídas.
- Contas e dívidas com vencimento e marcação de pagamento.
- Conteúdo educativo introdutório sobre orçamento, dívidas, reserva e investimentos.
- Interface responsiva, instalável como web app quando o navegador permitir.

## Executar

Abra `index.html` em um navegador ou hospede os arquivos estáticos.

## Importante

**Esta é uma primeira versão local.** Os dados são salvos no `localStorage` do navegador, sem autenticação, sincronização ou backup. Limpar os dados do navegador pode apagar registros. Não inserir dados bancários sensíveis. Conteúdo educacional não constitui recomendação personalizada de investimento.
